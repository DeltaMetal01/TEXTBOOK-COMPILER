# md2a5 · lightning（通用版）

> 一份 Markdown 讲义，进，一份**可打印的 A5 彩色语义版 DOCX** 出。
> 配套的 `SKILL.md` 是一套学科无关、开箱即用的**讲义生成方法论**——板块制、三层体系、例题/习题分离、存疑点、闸三验收。
> 它想复现的，是那种你读书时最缺、却最贵的东西——**有人盯着你，逼你真的动脑子**。

---

## 一个我们都经历过的事

你有没有过这种时刻：

深夜，一个人对着一章新内容。书翻完了，例题看完了，脑子里冒出一句"嗯，我懂了"。合上书，第二天做题，手停在半空——**其实没懂**。

不是你笨。是"读书以为懂了"和"真懂了"之间，隔着一道谁都跨不过去的坎：**没有人中途打断你，问你一句"等等，你真能算出来吗？"**

遇过好老师的人都知道，真正让你长本事的，从来不是那本讲得漂亮的讲义。是老师讲着讲着突然抛来的一个问题、一句"你刚才那步为什么这么走"、一个换了个数字让你当场卡住的变式、一个故意没说完留给你想的钩子。这些动作加起来，才叫"教"。

可我们大部分时间，是独自在学的。

---

## 于是有了这份东西

`md2a5` 想做的事很朴素，也很贪心：**在一张纸上，把"好老师坐在旁边"的效果，尽量还原出来。**

它不追求把知识讲得更多——网上的讲解已经够多了。它追求的是，让你读这份纸的时候，**大脑真的在转**，而不是顺滑地滑过去、然后什么都没留下。

怎么做到？靠的不是炫技，是把那些"对话里才发生的动作"一个个固定成文档结构：

- **三问**（记忆 / 理解 / 应用）挂在每个板块的开头和结尾——带着问题进，合上才知道答得出答不出；
- **自问自答**在你最容易"一看就懂"的地方，冷不丁把你拦下来；
- **存疑点**故意不答，给你留一个真实的欠债，逼你回来找人清算；
- **镜像题对**把"同一个考点、条件反过来"摆在一起，你撞一次，才真懂是哪个条件翻转了结论；
- **编号即坐标**，让你任何时候都能跳回正文那一小块，而不是在一堆复制粘贴里迷路。

读完你会觉得，这不像一份"讲义"，更像一场**写下来的对练**。

而它交付的，是一份**翻开就能用、独立自足**的 A5 小册子——没有"完整版"和"精简版"两版互相找，没有"详见 XX"把你踢去别处，没有压缩到只剩结论的目录。

> **这一份，就是唯一的正本。**

---

## 但它不只是"写得好"——它还"印得对"

讲得再好，落到 Word 里如果化学式缺了氯、上下标丢了、表格整片空白、符号悄悄变成了别的字，那一切白搭。

这一关，比想象中凶：宋体对 Unicode 上下标覆盖不全，一章能静默漏掉两百多个上下标；化学式残缺比写错更隐蔽；数学符号会**变成另一个符号**静静通过；表格渲染成空白、XML 顺序错一位 Word 直接打不开——而渲染验证却显示"通过"。

所以转换流水线（源码在 `脚本源码.md`）做的事是：**pandoc 搬运 + 表格修复 + 语义上色 + 页码 + 顺序归一化**，全程不让你用 python-docx 把内容重打一遍（每重打一次就掉一批字符）；最后用 `verify_docx.py` 这道闸，**14 类检查**专门抓"脚本没报错、但实际做错了"的静默失效。

它不是帮你"生成一份文档"。它是帮你**别把一份其实已经错了的文档，信心满满交出去**。

---

## 这份东西，是给谁的

- **自学者**：你一个人扛一整章，它需要替你当那个"会追问的人"。
- **教书 / 带人的人**：你懒得每章手写讲义，它按一套被反复踩坑打磨过的方法，替你产出结构严密、推导不跳步、内容自洽的稿子。
- **任何想把自己脑子里的知识"固化成可打印物"的人**：方法学科无关——数学、物理、化学、语文、英语，骨架是同一套。

> 它面向的是**自学型读者**：接受教科书式严谨，怕干瘪定义，文档保持中性、不玩梗。
> 深度标定只有四条标尺，核心一句话——**往"讲清为什么"多走一步，往"题目更难"一步都别走。**

## 跑通一份

lightning 的核心是两份：`SKILL.md`（方法论，顶部已带 `name`/`description` frontmatter，可直接被 skill 加载器加载）+ `脚本源码.md`（转换流水线全部脚本源码）；另附 `example/demo.md` 作演示样例。要真正转换，先把源码落成脚本：

```bash
# 1) 从 脚本源码.md 把每个代码块存成 scripts/ 下同名文件，md2a5.sh 需 chmod +x
mkdir -p scripts && <把 脚本源码.md 里的代码块逐一存好>

# 2) 按 SKILL.md 的规范写一份讲义 .md（参考 `example/demo.md`，本版自带）
# 3) 转换：
bash scripts/md2a5.sh 你的讲义.md
# 默认输出 你的讲义_A5打印版.docx（A5 148×210mm）

# 4) 验收（必做）：
python3 scripts/verify_docx.py 你的讲义_A5打印版.docx 你的讲义.md
# 加 --pedagogy 启用「讲义约定检查」；--selftest 跑脚本自检确认验收本身可信
```

前置只要两样：**pandoc**（锁 `3.1.11`，别用 `3.11`）和 `python3`（仅标准库）。

## 想要"按我的情况定制"？去看 thunder

lightning 是**纯通用版**：没有读者画像、没有定制向导，干净、可移植，适合直接当一份"怎么教人"的指令塞进任意 AI / skill 加载器。

> 本目录 `SKILL.md` 已带标准 skill frontmatter（`name` / `description`），复制到 `~/.workbuddy/skills/md2a5-lightning/SKILL.md` 即可作为 skill 被加载；`脚本源码.md` 是它配套的流水线参考。

如果你想要个性化——按你的学习阶段、教材版本、深度偏好、薄弱类型来调——那是 **thunder（完整版）** 的事：它多了 `collect_profile.py` 交互向导和 `apply_profile.py` 注入，会自动在稿首写一行"适配声明"。同仓 `thunder/` 即是。

## 这一版，诚实地留了白

这是**脱敏后的通用版**：不含任何个人画像、地区或教材绑定，开箱即用。它故意没做两件事，留作 thunder 版：

- **不含读者画像定制层**——lightning 不绑定任何人的习惯；要定制去 thunder。
- **不含学科专属模板**——只留学科无关的方法论，数学 / 物理 / 化学 / 语文 / 英语的分科写法不在本版。

留白不是偷懒，是**先把骨架立住，再长肉**。

## 为什么开源

这套东西，最初是私人的——为一个具体的人、按一套具体的习惯、在一台具体的机器上长出来的。它救过很多个"以为懂了其实没懂"的夜晚。

但方法论本身，不该困在那台机器里。

所以我们把它**脱敏、工程化、砍到最干净**，发出来：删掉所有个人数据和绑定，只留那套"怎么让纸面上的讲解真正教到人"的骨架，和那条"让文档印出来不出错"的流水线。

如果你也一个人扛过一整章，如果你也想要一份"会盯着你"的讲义——拿去用，改它，让它替更多人当那个"坐旁边的人"。
