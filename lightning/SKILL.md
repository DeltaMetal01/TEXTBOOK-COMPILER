# 章节精讲 · 讲义生成方法论（通用内核 v4.3）

> 变更史已迁出正文（避免污染每次加载的上下文），追溯见同仓 `thunder/CHANGELOG.md`。

> **定位**：以知识库为唯一源，一次性产出整章完整讲解稿，非交互式、非增量对话。产物独立自足，翻开即用。
>
> **设计哲学：在离线、无 AI 介入的场景下，复现对话式学习（dialogic learning）的认知效应。**
>
> 对话之所以有效，不在于"讲解"本身，而在于其间持续发生的**主动检索、追问、换元检验与留白钩子**。将这些动作物化为纸面结构（三问、存疑点、自问自答），产物便从"讲解"升格为"模拟对练"。
>
> **产物纪律：不存在"压缩版"，只有"即用版"。**
>
> 交付件即唯一正本，不保留另一份"完整版"供回退。减负只能经由**提升信息密度**（语义着色 / 表格化 / 判据化 / 交叉引用）实现，**绝不能删减内容**——见 §1 末条与 §7。
>
> **读者模型与认知深度，由 §2 标定**——该节决定全文语气、密度与取舍，开工前必读。

## §1 设计哲学与产物纪律

本 skill 的核心主张：高质量自学材料的瓶颈不在"讲得全"，而在"讲得让大脑真动起来"。据此确立三条基础纪律，下文所有规则皆由其派生。

1. **对话动作物化**。AI 对话中真正产生学习增益的动作——提问、追问思路、抛新角度、换数字检验、留钩子——一律固化为文档结构，使离线阅读时仍能触发同类认知操作。三问（§5）、存疑点（§5）、自问自答（§5）即其纸面形态。
2. **内容单源、逐 token 直出**。Markdown 是逐 token 打出的唯一内容源，无中间层；以 `python-docx` 之类库逐段重构 docx 等于**把内容重打一遍**，每重打一次 ₂ ₃ ⁻ ²⁻ ³⁺ ⇌ 即掉一批（该事故实测发生三次）。docx 一律经 pandoc 命令行转出。
3. **密度优先于篇幅**。同一信息量，扫读更薄、定位更快，靠的是结构手段而非删减。判断权交还内容本身：该讲多少讲多少，讲完为止。

**反面约束（派生自上述纪律，违反即毁产物）**：
- 不得出"压缩版 / 精简版 / 一页通"等第二份正文（见 §11 失效模式 ⓪）。
- 不得覆盖 / 整份重生成来"修正"（改 N 处只做那 N 处增量编辑，见 §2 第 6 条）。
- 不得手改 docx 或其内部 XML（OOXML 子元素严格有序，错一位即损坏，见 §2 第 13 条）。

## §2 读者模型与认知深度标定

> 本节回答两问：**面向谁**，**讲到多深算够**。开场先读，效用高于十条格式规定——格式可改，深度错了整份报废。
>
> 本 skill 面向**自学型读者**：接受教科书式严谨，排斥干瘪定义；文档保持中性，不混入闲聊梗。

### 2.1 深度标定：四条标尺

**① 补"为什么"，不堆难度。** 深度是**纵向**的——结论由来、定义必要性、历史卡点；不是**横向**的——更难、更偏、更怪的题。

**② 推导不跳步。** 从定义到结论每步落字，数学尤甚。读者耐受严谨，不耐受"显然可得""易知""同理"。判据：教材正文推导密度即上限参考。

**③ 抽象概念必配实例链，数量由判断决定。** 每个新概念：先给**能算 / 能看**的具体例 → 再给抽象定义 → 回例验证。**默认一例足矣**；加第二、第三例当且仅当：概念离日常经验越远、或该章反复栽处。难概念只给一例 = 未讲透；简概念硬凑三例 = 注水。拿不准往多加，勿往少砍。

**④ 上至中档，不越高考，压轴仅作点缀。** 不做竞赛、不引大学内容、不炫技。教材正文深度为上限，真题考法为范围边界。

> ⚠️ "不越高考"仅约束正文，不约束联系层：

| 层 | 是否受高考范围约束 |
| --- | --- |
| 🟢 必记 / 🔵 讲解（**正文**） | **受约束**——不做竞赛、不引大学内容、不炫技 |
| 🟣 联系（素养区） | **不受约束**——本即素养载体，可超纲 |

超纲内容非"降级"入 🟣，而**本属 🟣 自由区**：史料、跨域、更深原理、有趣延伸皆可入。唯一要求是**标注"不考"**，以免读者误判为背诵项。（例：化学平衡可引勒夏特列原理的工业背景；物理圆周运动可提开普勒。此类超纲但属素养，正宜入 🟣。）

### 2.2 篇幅：由内容决定，不设页数上限

不设页数触发器——隐性天花板会反向限制内容。页数降格为 §13 质量闸的**报告项**：`verify_docx.py` 报出页数，交人判断"真需要"还是"注水"。防膨胀主防线在**动笔端**（全景先出，确认后再写正文），该兜底不省。

### 2.3 但不许横向堆砌

不设上限 ≠ 可灌水。唯一约束是密度，非长度：
- 一概念一例足用则不补第二例（第二例仅当第一例未讲清时才配）
- 同一意思不许换三种说法讲三遍
- 🟣 联系层**每个知识点必有一条**（§4），且**必须落回本条**——抛出不收的联系 = 顺便科普 = 凑数
- 不为"显得全面"把沾边内容都写进来

**判据**：每段动笔前自问——**读者读完这一段能多得一点什么？** 答不上来则不写；答得上，多长都写。

### 2.4 反面清单（读者明确排斥的）

- ❌ 出"压缩版 / 精简版 / 浓缩版 / 一页通"另一版本（见 §1 末条）
- ❌ 正文写"详见提纲 / 站台"，或站台出现正文未载结论
- ❌ 只给定义不给来路（干瘪定义病）
- ❌ 跳步、"显然""易得""同理可证"
- ❌ 罗列步骤不讲**为何如此想**
- ❌ 通篇抽象，无具体数字与实例
- ❌ 文档玩梗
- ❌ 为显难而加难度（横向堆砌，非深度）

### 2.5 一句话判据

> 拿不准深或浅时——**朝"讲清为什么"多走一步，朝"题目更难"一步都别走。**

## §3 生成前约束（十五条铁律）

读完即开工，**不复读、不回显**。

1. **先对 §2（读者模型与深度标定）**。它决定语气、密度、取舍——谁在读、怕什么、讲多深。
2. **内容只写一次——写进 `.md`**。docx 由脚本从 md 转出，不碰内容。（机制见 §1 第 2 条。）
3. **一次一份（一章或一册），整段输出**。不分批、不中途停问"要不要继续"。要的是一整段直接塞出。
4. **先列全景再展开**（§4）。这是"讲细讲碎又不漏"的保障机制。
   - **3a 每抽象概念先给数字实例再形式化**：入口必须具体，直接甩定义 = 看不懂。顺序恒为：具体例 → 抽象表述 → 为何如此抽象。禁"显然""易得""不难看出"。
   - **3b 篇幅由内容定，不设页数上限**：该讲多少讲多少。唯一约束是密度非长度——一概念一例、同义不换三说。
   - **3c 重心在基础与中档，不在压轴**：基础 + 中档讲透，压轴至多一道且可省。不为凑上限堆难题。
   - **3d 二八定律 + 边际效益**：80% 力气给 20% 真拉分者。高频写足、低频带过、**偏难怪不写**。每多写一段前问：此点收益配得上其篇幅与读者时间否？
5. **不许覆盖源文件**。仅在别处另存。
6. **不许整份重生成来"修正"**。改 N 处只改那 N 处（增量编辑 md）。双文件场景：改 md → 重跑脚本 → docx 自动跟上，永不改 docx。
7. **自包含**。禁"见前文 / 如上所述 / 同理可得 / 显然"。
8. **末尾必写「── 本份完成 ──」块**，块内仅留一句面向学生收尾话（写法见 §9）。
9. **化学式 / 数学符号逐字核对**（§11 失效模式 ②③）。与模型强弱无关，属输出侧物理事实。
10. **表格 ≤3 列**。脚本能修宽与边框，但**救不了列数**——A5 三列已是极限，多列即使不溢出也挤不可读。三列以上改文本竖排。
11. **必须声明知识口径**（§5 口径声明）。凭知识库生成时版本差异是硬风险。
12. **学习方法只做不标**（§5）。主动回忆、间隔重复、交错练习靠**结构实现**，禁在文档写方法名。
13. **不许手动改 docx 的 XML**。OOXML 子元素严格有序（如 `pBdr` 须在 `spacing`/`ind` **前**；`tcPr` 内须按 `tcW → tcBorders → shd → tcMar → vAlign`）。表格要改，改 `fix_tables.py`。永远经改脚本重跑，不手改产物。
14. **转完必跑渲染验证**（§10）。XML 语法错误文件层面不可见，唯渲染器报。
15. **工作区找不到脚本时，不许裸 pandoc 硬上**——于 `scripts/` 用源码重建（换 skill 会清空工作区，脚本源码独立于该目录）。

## §4 知识架构：板块制与三层语义模型

### 4.1 板块制（先分层，再展开）

一章切 **2–5 个板块**（按内容定：天然两大块的章硬切三块反碎），板块下挂 3–7 知识点。编号 `[板块号.知识点号]`。

```markdown
## 本章知识全景（先列后讲）

**板块 1：[板块名]** —— 一句话定位
- [1.1] 知识点
- [1.2] 知识点

**板块 2：[板块名]** —— 一句话定位
- [2.1] 知识点
...
```

**分板块之由**：15 知识点平铺是流水账；分块后见骨架（框架优先，合读者认知习惯）；三问挂**板块级**而非每知识点，篇幅可控；编号带板块号，复习定位更快。

**全景粒度**：一章 8–20 知识点为宜。过少 = 未讲碎；过多 = 切太细，合并。（板块数不在此列：2–5，按内容。）

### 4.2 三层语义模型（🟢🔵🟣🟠）

🟢 层是**本章必记硬事实**（等价课本黑体字：默写唯一依据），不依赖外部材料即可默出。

| 层 | 内容 | 地位 |
| --- | --- | --- |
| 🟢【必记】 | 定义、公式、定理、结论、必背事实 | **地基 + 默写依据**。精确、完整、不含糊 |
| 🔵【讲解】 | 为何如此、如何推来、怎么用、坑在哪、考试怎么考 | **主食**。讲细讲碎，不跳步 |
| 🟣【联系·生活与跨域】 | 生活经验、跨界应用、换讲法、后续教材剧透 | **味精**，但**每知识点必有一条** |
| 🟠【前后·联系】 | 时序 / 考向 / 同构 / 跨学科——**知识的位置** | **坐标**。见 §4.4，维度优先 |

**🔵 与 🟣 之分**：看主语。主语是"知识本身" → 🔵（服务理解）；主语是"知识外的世界" → 🟣（建立联系）。同一事可两角度各写一条，不冲突。

**🔵 两高价值子类（打 tag，优先写）**：
- **`#落差`**——教材讲简化版，考试考加深版。
  ```
  🔵【讲解·落差】#落差 教材通常只讲 XX（简化前提：__）。
  考试常考加深版是 YY —— 区别在 __，触发条件：看到 __ 即想用 YY。
  ```
- **`#易错`**——讲全了但实会栽处。与"落差"别：落差是"教材未讲全"，易错是"讲全了你易看漏 / 记反"。

**🟢 层写法要求**：精确到能默写（定义写全，禁"等等""之类"）；公式写全（各字母含义、单位、适用条件紧跟）；多等价表述给主表述 + 括号注别称；先给具体数字例再给抽象表述（具体化原则）。

### 4.3 讲细讲碎的骨架（不跳步）

每知识点按下骨架展开（🔵 内四问即主食）。薄弱科目常见问题非"未学会"而是精度（一看就懂一算就飘），故"为什么"与"坑"比"是什么"更重要。

```markdown
📍 [N.M] 知识点名称

🟢【必记】精确定义 / 公式 / 结论（+ 各字母含义、单位、适用条件）

🔵【讲解】
- 为什么是这样（来龙去脉、推导，教材省略的推导要补）
- 怎么用（识别特征：看到什么即想到用它）
- 坑在哪（常见误用、边界条件、易混点）
- 检验（怎么确认没算错：量纲检验 / 极端值 / 回代）

🟣【联系·生活与跨域】……（**必写**。条数 = 知识点条数，一知识点一条，整章不可为零）

🟠【前后·联系】
前置：__ ／ 后置：__
考向：__（题型位置 + 频次/占比）
同构：__（在别章以何名再现）
跨学科：__（在别科怎么用）
其他：__（生活 / 技术 / 剩余联系）
```

**边界**：细在**为什么与坑**，非在 🟢 堆废话。🟢 短而精确，🔵 长而透。

### 4.4 🟠 前后·联系：标"位置"非"顺序"

名仍"前后"，装的非顺序。顺序只答"先学谁"；本节标该知识点在整张网上的**坐标**——时间轴站位、考卷站位、别科站位、与谁同体。

**五维，能写几写几**：

| 维度 | 回答什么 | 例子 |
| --- | --- | --- |
| **前后**（时序） | 理解它需先有什么 / 它接哪 | 前置：一次函数与斜率（必修一）；后置：导数几何意义（选必三） |
| **考向** | 在哪类题被掏出、频次与占比 | 高考向量压轴常见入口；本章高频，约 1–2 选择 |
| **同构** | 在别章以何名再现（同式换皮） | 解析几何"两直线垂直"判定，本质仍是数量积 = 0 |
| **跨学科** | 在别科怎么用 | 物理必修一力学、必修二速度合成直接调用本节 |
| **其他** | 生活、技术、后续教材剧透等剩余联系 | 无人机姿态解算、游戏引擎向量运算 |

**写法**（整段一 🟠 橙，与 🟢🔵🟣 平级，勿挤成黑块）：

```markdown
🟠【前后·联系】
前置：一次函数图像与斜率（必修一）
后置：导数几何意义（选必三）
考向：高考向量压轴常见入口；本章高频，约 1–2 选择
同构：解析几何"两直线平行"用同一式，仅换名
跨学科：物理必修一力学、必修二速度合成直接用本节
其他：无人机姿态、游戏引擎向量运算
```

**四条导向（方向非死限——勿写成"一句带过"把模型憋死）**：
1. **维度优先于字数**。多写一维 > 把同维写长。
2. **内容不够即空该行，勿凑**。硬凑联系比没有更糟——读者会当真，记住假联系。
3. **后置仍在高中范围**；超纲降级入 🟣。**考向可写占比**，但须真实判断（高频 / 偶考 / 压轴常见），禁编造具体分数。
4. **篇幅不硬性封顶**。此块实测偏长，但横向不扩、纵向加深：维度可续加，总长勿再涨。

**双重编码**：能用文本结构图说清者（流程、层级、关系），以缩进 / 箭头画纯文本图，与文字并列。勿用真图（打印不友好）。

## §5 交互式学习机制（自问自答 · 方法隐式化 · 存疑点）

### 5.1 自问自答（离线复原对话之核心）

打印稿最大弱点："读时以为懂了"。读者"一看就懂"体质最危险——无人打断。自问自答强制中途停做一次检索。

**第一层 · 板块级（必挂）**：每板块 3 核心问，卡三层：
- **Q1 记忆层**：能否默出
- **Q2 理解层**：为何如此
- **Q3 应用层**：换数、换景还行否

> ⚠️ **Q3 硬要求：必带具体数字或具体场景。** 实测 Q3 最易写成"套一遍公式"（如问"写自发最低温表达式"，答"令 ΔG=0 得 T=ΔH/ΔS"——仅复述公式，判不出真会）。合格 Q3：给一组具体数值让读者算，或换条件再问。例：
> - ❌ 「ΔH>0、ΔS>0 反应何温自发？」（套公式即可）
> - ✅ 「若 ΔH = +180 kJ/mol、ΔS = +200 J/(mol·K)，该反应 25℃ 下自发否？几度以上才自发？」（要算、换算单位、判）

**Q3 是"真会没会"判据**——会了过，不会换角度，还不行回上层。

**位置**：问题挂**板块开头**（带问题读，注意力有靶），答案放**板块末尾**（板块内自成小闭环，反馈周期短）。

```markdown
## 板块 2：[板块名]

### ❓ 本板块三问
- Q1（记忆）：……
- Q2（理解）：……
- Q3（应用）：……（带具体数字或场景）

（知识点讲解……）

### ✅ 三问简答
- Q1 → ……（只给要点，不展开）
- Q2 → ……
- Q3 → ……（给完整计算过程，非只给公式）
```

**第二层 · 知识点级（AI 判断，非每处挂）**：判据（满足任一才抛，余不抛）：有 `#落差` 标记 / 有 `#易错` 标记 / 属"一看就懂一算就飘"型 / 跨章节关联。**纯记忆、无坑者不抛**——勿为凑数到处问。

```markdown
💬 自问：……？
✅ 自答：……（要点，不展开）
```

**自我解释 / 费曼提示（少量）**：精讲题解析后，**偶加**一句印出提示（非留白栏）：`（讲一遍给自己听：这一步为何如此走，能否一句话说清）`。这是提示句非空栏；调用方自会批注，勿留待读者填的框。

### 5.2 学习方法：只做不标

**唯一规则：方法靠结构实现，禁在文档写方法名。** 见"回忆一下"对（那是**动作**）；见"（此处运用主动回忆法）"错（那是**标签**）。方法名一现，文档即从"学习材料"降为"关于学习方法的说明"，读者注意力被挪离内容。

### 5.3 🔮 存疑点（AI 故意不答）

**少量、独立、不影响主体。** 作用：给一章答不了、但后续能答的问题，引读者读毕回来找 AI 清算（直报编号即可）。好处：制造真实欠债点 + 给下章留接口。

**硬约束（防偷懒）**：主体必须完整交付，存疑点是额外非缺口。绝不许以"留给你思考"逃避本该讲清者。

**判据（一章 1–3 个，仅在这些处留）**：条数不设硬指标，1–3 仅常见区间——够真就留，勿为凑"1–2"砍真问题；凑不出写 1 甚至 0。留点须为：跨章节需后文才能完整答 / 能引出下章 / 值得深想有探讨空间 / 确有多种讲法需读者确认本地口径。

**格式**：

```markdown
### 🔮 存疑点 [S1]
问题：……

（此处不答。回来时直问「[S1] 那个」，或自推一遍。）
```

**必须编号** `[S1]`，便回引。

**△ 原地标记（可选但推荐）**：正文凡"口径拿不准 / 版本可能有异 / 需读者确认本地教材"处，**当场标 △**，编号与存疑点对齐（△S1、△S2），文末统汇成 🔮 块。读者读到一半遇不确定处**当场知"此处存疑、非我没懂"**，勿读至结尾方知、再回头寻。

**实测经验**：好存疑点是"两已讲说法看似矛盾"——如"恒容充惰气平衡不动"与"压强改变影响 Δn≠0 平衡"。此类逼出真概念澄清（钥匙是分压），价值远高于单纯延伸问。

### 5.4 跨章清算：必须对账，勿靠记忆

**事故**：第 9 章挂 S1、S2，第 10 章只清算 S1——S1 接上因**当时记忆里有它**，S2 漏（纯靠运气非流程）。故生成新章前必跑此步（写入工作流，勿跳）：
1. 读进度索引**存疑点总账**（各章挂哪些 S、各何状态）
2. 逐条处置：**清算**（本章讲掉）/ **明确挂靠点**（"留至第 X 章，因…"）/ **标不要求**
3. 本章新挂存疑点登记入总账
4. 章末复习总结写明"本章清算哪几个、新挂哪几个"

**不允许"上章有存疑点、此章未提"**——要么处理，要么明说此章为何不处理。

**进度索引存疑点单独列一行**，勿只写数字：

```markdown
| 章 | 存疑点 | 状态 |
|---|---|---|
| 第9章 | [S1] 中点场强为零是否=没有场 | ✅ 第10章 [2.1] 清算 |
| 第9章 | [S2] 接触平分是瞬间的吗 | ✅ 第10章 [3.1] 清算（同静电平衡机制）|
| 第10章 | [S3] …… | ⬜ 待清算 |
```

### 5.5 知识口径声明（凭知识库生成的硬风险）

AI 知识库系全国平均口径，可能与读者实际教材对不上。
1. 开头声明（按科目选一句）：`（本份按你所用教材的现行口径生成。若讲法不同，直接指出，我只改那一处。）`
2. **版本差异大科目特别注意**：化学（方程式细节、实验装置）、语文（课文篇目特定）、历史 / 政治（表述口径）。
3. 拿不准处**标出非猜**：`（此处不同教材讲法可能有异，常见两种：A.__ / B.__，以你的课本为准）`
4. 若提供考情，**优先服从**。

注意：口径问题勿过度纠结，标出即可，勿因拿不准就不写。

## §6 习题编排与镜像训练

题全自编。**不规定"一章几道"——按内容自然分配。**

### 6.1 核心原则：仅例题给解析

**例题给完整解析；习题与综合题一律不给答案、不给解析、不给提示。** 理由硬：
1. 答案印纸上，眼会自瞟，主动回忆即废。不给答案，做不出读者会**回来找 AI 对**（§14 流程 3），此"回来"即间隔重复。
2. 解析最占篇幅，剥去省下全留正文。

**红线**：不给答案 ≠ 给烂题。题须可解——数字给全、条件给足、考点明确。心中必有完整解（仅不写进文档），读者回问能立给。

### 6.2 分配方式：随"块"走，非随"章"走

一知识点小块，或关联紧密大板块（看关联度与难易），配一组：

```markdown
一组 = 例题（给解析，示范怎么想）
     + 习题（不给答案，自走一遍）

（数量按内容定，不写死——"一组几道"类数字限制是屎山，久用会把内容削足适履。）
```

- **关联紧、难度大** → 一知识点小块即配一组
- **关联紧但简单** → 整板块合起来配一组足
- 判据是**内容本身**非凑数

### 6.3 在精不在多（通用倾向，非形态规定）

**把一道题用到透，非铺量。** 判据是"此题是否值得做第二遍"，非"凑够几道"。理由：题练**精度**非刷覆盖——读者记忆佳、缺稳定性，**重复同动作比多见几题有用**；铺量还挤掉正文该有推导。

> ⚠️ "在精不在多"非"每题必拆多问"：
> - 形态随科目与板块走，不统一：有题宜一题多小问串完一板块；有即单问小题更宜。
> - 非全科适大题：文科（语文、英语）、部分化学，乃至数物某些板块，**全做多问大题反别扭**。单问短题同是"精"——只要打在那具体坑上。
> - 看着平衡就好：一章大题小题混着有，比全大或全小都正常。勿为"多问"拆题，那是凑数。

数量参考（数学科有独立量化标准，见 §4 之外分科件）：余科按内容定不写死——**"一组几道""一题几问"类数字限制久用会把内容削足适履**。

### 6.4 章末：综合验收

```markdown
## 🎯 综合题（全章融合 · 不给答案）

**综1** 题目（跨 [1.3] + [2.1] + [3.2]）
> 考什么：__（只给考点清单，不给思路、不给答案）

## ✏️ 章末习题（不给答案）

- 末1 —— 考「__」，坑在 __
- 末2 —— 考「__」
```

- **综合题**：跨 2 板块以上，全章融合总验收。数量按内容定不写死。
- **配套习题**：按需给，配综合题做完整验收。数量按内容定不写死。

### 6.5 🔁 镜像题对（嵌例题与习题内）

**同考点、两条件相反版本。** 实测最有效一类。摆法：例题示范 A 条件怎么走（给解析），紧跟习题给 B 条件（不给答案，让读者自撞）。例：例题 Δn=0，习题 Δn≠0——**撞出才真懂何条件翻转结论**。

实测：`H₂ + I₂ ⇌ 2HI`（Δn=0）vs `N₂O₄ ⇌ 2NO₂`（Δn≠0），同判据清单结论相反。

**怎么找**：看此章有无"某量取值会翻转结论"处——化学：Δn 是否 0、ΔH 正负、ΔS 正负；数学：判别式正负、参数是否越界、定义域是否跨区间；物理：是否有摩擦、是否考虑空气阻力、滑动 / 滚动。**每组例题 + 习题能成镜像对者优先做。**

### 6.6 通用规则

- 例题回代**必须往回算一遍**，禁写"代入检验成立"
- 题贴近教材常见题型，勿编偏难怪
- **不做分值区间**（那是给卷子用的）
- 读者回对答案：**答错 → 指卡哪步让读者自重走；答对 → 确认关键步**。勿直报答案，除非读者明要

## §7 信息密度工程（变薄靠密度，不靠删内容）

本节是 §1 末条"密度优先"的落地手段。目标：同信息量，读更薄、扫更快——**一字不删**。

### 7.1 四条手法（按性价比排）

**① 颜色分区代大段解释**（已固化进脚本，`colorize.py` 自动做）：同块内 🟢 必记 / 🔵 讲解 / 🟣 联系 / 🟠 位置 / ⚠️ 坑 / 🔮 存疑各固定色。眼扫到色即知此行性质，**勿读完首句才知在讲什么**。最省篇幅一条——彩色输出可做分区，克制使用。

**② 判据一律表格化 / 箭头化**：叙述改"触发条件 → 动作"行：

| 看到 | 就用 |
| --- | --- |
| since + 时间点 | 现在完成时 |
| yesterday / ago | 一般过去时 |
| Look! / at the moment | 现在进行时 |

比写三段"since 引导时间状语从句时……"快且**可直接扫**。判据卡是此条主要产物形态（英语 / 语文分科已全面采）。

**③ 交叉引用代重复展开**：同联系在别讲义已讲透，此**只写坐标不重展开**：

```markdown
同构：见《英语·必修一》[3.1] 阅读四类题型判据（那里已展开，此处不重复）
```

信息未丢（读者找得着），篇幅未占。**禁反向——勿为省事把正文删掉只留引用。**

**④ 编号即坐标：所有结论带 📍[N.M]**：易错汇总、站台、复习总结、存疑点清算，全靠编号回跳正文。故"汇总"不需复制结论原文，写编号 + 一句即够，**汇总页不膨成第二份正文**。

### 7.2 三不许

- ❌ 用"删低频考点"变薄（见 §1 / 二八）——那非密度是缺失
- ❌ 用"把讲解砍成结论"变薄——砍掉的"为什么"正是读者最需
- ❌ 用"压缩字号 / 行距"变薄——排版规格已固化（§10），动它伤可读性

### 7.3 判断标准

> 变薄后，读者**扫一遍**拿全骨架，**读一遍**拿全内容。扫不全骨架 → 结构有问题；读不全内容 → 那是删多了非压好了。

````markdown
**不只是"这章讲什么"，更是"这章站在地图哪一格"。** 三条链，各 1–3 行：

```text
````

- **去向链**：此章出口通哪（下章 / 下册 / 后续专题）
- **调用链**：在哪类题、哪场景、哪科被实际用上（对应 🟠 考向 / 同构 / 跨学科）

**章级三问 ≠ 板块三问。** 板块三问"带问题读这一段"，章三问"带问题读全章"，层次更高。答案不在此给——章末复习总结收。

```markdown
## ❓ 本章三问

- Q1（这章到底在说什么）：……
- Q2（为什么是这样，非别的）：……
- Q3（学完能拿它做什么）：……（带具体数字 / 具体句子 / 具体场景）
```

### 8.1 🗺️ 本章站台 · 全章索引页（存疑点后、复习总结前）

> **名"站台"因它只索引非第二份讲义。**

**一行一知识点，只写定位不写内容。** 用途：回看扫一眼即想全章骨架；考前快过；状态一般时只看此也不至全丢。注意：此是**使用方式**（读者已读正文后回看路径）非产品形态——**正文勿因有站台少写任何东西**（§1 派生禁令）。

**写法**：一行一条，只写结论，不写推导 / 例 / 为什么；保留 📍 编号（编号即坐标，见 §7.1④）便回正文定位；缩进表板块层级；**一页内**（A5 一页）。超一页 = 编号切太碎——该合并条目非删内容。

**两条硬约束**：站台内**禁出现正文未写结论**（否则正文退化）；正文内**禁写"详见站台"**（站台是索引非正文替身）。

```markdown
## 🗺️ 本章站台（全章索引页）

- [1.1] 结论一句话
- [1.2] 结论一句话

**板块2 [板块名]**
- [2.1] 结论一句话
...

**全章就三件事**
1. __
2. __
3. __
```

**末"全章就三件事"是本份最后一刀**——若整章只记三句即这三句，逼出真优先级。它是索引最高层：**指向正文非替代正文**。与"复习总结"别：站台是索引（有何、在哪），复习总结是教训（最易错什么）。两者都要不重。

## §9 生成节奏与收尾规约

### 9.1 一次输出完整章：禁"分批"、许"分次"

**先分两词**——非一回事：

| | 定义 | 是否许 |
| --- | --- | --- |
| **分批** | 输出一段后**停问用户**"要不要继续""先看这部分？" | ❌ **禁**。要的是整段直接塞出 |
| **分次** | AI 自**连续吐两段**（或更多），中间不停顿、不询问、不等回复 | ✅ **许**，长章推荐 |

分次非分批——用户见仍完整一份，中间未被打断、未被迫回应。长章（知识点 >12）时**主动分次**，是缓解"越写越松"正当手段非偷懒。

### 9.2 结构性兜底：先骨架，后回填

**越写越松只能缓解非根治**（长输出尾部质量衰减客观）。故用**输出顺序**把损失压最小：**先写全章骨架 → 再逐板块回填 🔵 层**。

```markdown
第一遍：全景 + 全章所有知识点 🟢 必记层（+ 编号、+ 🟠 前后·联系）
第二遍：逐板块回填 🔵 讲解层、🟣 层、💬 自问
第三遍：三问、例题 / 习题、易错汇总、综合题、站台、复习总结
```

**为何兜得住**：即使尾部疲劳始松，松的只 🔵 层（讲解），而 **🟢 必记层（全章最值钱、最能默写者）已第一遍全写完且质量均匀**。风险从"骨架缺失"降级"讲解变薄"——后者补易得多。注意：此是**输出顺序**非让用户分两次看，最终交付仍一份完整文档。

### 9.3 末尾必写（不写即违规）

```markdown
── 本份完成 ──

（一句话收尾：面向学生，回扣本章主线，例如"这一章从头到尾只做了一件事：……做完上面那些题后回来看这句话——能说出它在哪几处兑现了，这份就吃透了。"）
```

> ⚠️ **对 AI 说的话一律不写进文档**（"请验收" / "有问题直接说" / "改完重跑转换脚本"）。§13 质量闸 `delivery_leak` 会判为**交付说明泄漏** FAIL。这些话放**对话回复**里说。
>
> ⚠️ **本份完成块内勿写交付清单**（"包含：X 板块 / N 知识点 / 例题 X / 存疑点 X"）。那条清单是**对验收方报账**口径，学生不需要；且与文末"复习总结"重，已被当面指出 4 次。块内只留一句面向学生收尾话。页数 / 文件名 / 知识点数放**对话回复**说。

### 9.4 禁止的四种收尾

- **错误 A**：输出"本章全景 + 建议讲法"即停，说"建议重点看这几条" → 那是你给自己的执行计划非给用户建议。说要讲就得讲完。
- **错误 B**：末尾只写"── 自检通过 ──"即停 → 用户看不出写完还是在等。收尾信号是"── 本份完成 ──"块；"请验收"类对 AI 话写**对话回复**不进文档（否则 `delivery_leak` FAIL）。
- **错误 C**：先交付 md，等用户说"转 docx"再做 → 一步做完两文件，效率要求。
- **错误 D**：用"留给你思考"逃避本该讲清内容 → 🔮 存疑点是额外钩子非缺口，主体必须完整。

## §10 排版与交付链（实测调定）

### 10.1 版式与配色：皆在脚本，写 md 勿管

页面尺寸、字体字号、行距、页边距、表格样式、页脚页码——**全固化于 `a5-ref.docx` 模板**，由 `md2a5.sh` 自动套用。写 md 勿虑版式，勿为"好看"调写法。语义配色同理：🟢🔵🟣🟠⚠️🔮❓✅ 由 `colorize.py` **自动上色**（颜色 = 功能标识，正文近黑）。**勿在 md 自加颜色标记**——脚本只认符号，加了无用。真调版式改 `make_ref.py` 重建模板后重跑，**勿手改 docx**。

> ⚠️ 后续升级方向（反馈"只给标记行上色有点敷衍"）：下次试"章号 / 板块号用色块反白"（**未做**，优先试此）。守底线：底色只给整块，字色只给标记行，正文永近黑。

### 10.2 交付流程（一步双出）

```
1. 写  [章节]_精讲版.md              ← 唯一内容源
2. 跑  bash md2a5.sh [章节]_精讲版.md
        ├─ pandoc 搬运（AI 一字不重打）
        ├─ fix_tables.py 修表格（宽/列宽/边框/表头底色）
        ├─ colorize.py  语义上色（颜色=功能，正文近黑）
        └─ add_pagenum.py  注入页脚页码（居中 X / Y）
3. 得  [章节]_精讲版_A5打印版.docx   (A5 148×210mm)
4. 验证（必做，见下）
5. 交付：md + docx 两文件
```

md 是存档与增量修改唯一真源；A5 docx 是可打印版。

**绝对禁止**：
- ❌ 用 python-docx / docx-js 逐段构造 docx（= 重打字，掉字符）
- ❌ 手动编辑 docx 或改其内部 XML（schema 顺序错一位即损坏，见 §3 第 13 条）
- ❌ 先出 md 停住、等用户说"转 docx"
- ❌ 跳过渲染验证（XML 语法错文件层面不可见）

若无 `md2a5.sh`，用等价命令：`pandoc 输入.md -o 输出.docx --reference-doc=<a5-ref.docx 路径>`

### 10.3 转完验收

**全交一脚本，勿手写命令逐项跑**（手写会漏查某项）：

```bash
python3 scripts/verify_docx.py 输出.docx 源.md
```

14 项一次跑完，详见 **§13 质量闸三**。只强调一句：

> **渲染验证不能省。** XML 层面看着"正常"的文件，LibreOffice 可能直报 `source file could not be loaded`——唯真渲染才看得出。顺带拿页数。

### 10.4 验证主次：内容对错以 XML 文本层为准

**确认"内容有没丢 / 印错没"，必 grep docx 的 XML 文本层，勿用 pdftotext。** 实测：`pdftotext` 对**真上标 run** 还原不稳定——同文件一次还原成 Unicode 上标（⁻⁶），一次直平排成 `-6`，两结果异。拿它验收会得相反结论。

分工定死：

| 目的 | 用什么 | 说明 |
| --- | --- | --- |
| **内容校验**（负号在否、字符对否） | **docx XML 文本层 grep** | 唯一可信 |
| 文件没坏、页数多少 | soffice 渲染 + pdfinfo | 只做这两件 |
| 抽查排版 | pdftotext | 仅供参考，**勿据此改内容** |

**grep XML 文本层时正则须容属性**：`<w:t xml:space="preserve">` 常态，写死 `<w:t>` 会静默漏大部分带空格文本。用 `<w:t(?:\s[^>]*)?>(.*?)</w:t>`。

### 10.5 交付验收与脚本纪律

**交付时 md 与 docx 同给**：docx 供打印，**md 供全量验收**。读者阅读工具提取 docx 时会大面积损符号与 emoji（已遇 6 次以上），只给 docx 会让读者误判"文档有错"。

**一键验收（闸三）**：

```bash
python3 scripts/verify_docx.py 输出.docx 源.md    # 14 项一次跑完
python3 scripts/verify_docx.py --selftest         # 改完脚本必跑
```

**三道内容闸（看源 md 非 docx）**：

| 闸 | 抓什么 | 级别 |
| --- | --- | --- |
| `empty_field` | 🟠 的"同构 / 跨学科"填"无"或留模板占位 `__` | FAIL |
| `vague_cross` | 跨学科栏只写光秃秃学科名（"数学"两字）= 硬凑 | FAIL |
| `struct_complete` | 必备件清点：三问 / 例题 / 习题 / 易错 / 存疑点 / 站台 / 复习总结 | WARN |

前两道是同件事两面：勿硬凑亦勿留空。第三道只 WARN 不阻断——非讲义类文档（如方法说明）本无全套件，判 FAIL 误伤。"三问"用宽匹配（本章 / 本编 / 本册 / 本板块三问都算），写死"本章三问"会把合订本全判缺件（实测误报过）。

**改脚本三条纪律**：
1. **测试先行**：先定"已知错误用例"再写实现。写完实现再想用例会不自觉迁就代码，测出"通过"是假。
2. **改完脚本必同步源码副本**（整块替换），否则重建出旧版。
3. **改完脚本重跑 `--selftest`**，确认还能抓已知错误。

**备份命名规范**（整目录版本化，含 scripts 与源码）：改 SKILL.md 时另存带日期版本号备份（如 `bak_YYYYMMDD_vN.md`）；整版发布时进统一备份目录。两处都要有，勿只留临时那份。

## §11 失效模式库（实际踩过，必避）

**⓪ 压缩版陷阱（最易被"好意"触发）**：为"薄一点"删内容、出"精简版 / 一页通"、或把讲解砍成只剩结论。后果：读者拿到的非讲义是目录；回看得再开另一份，两套互找。对策：见 §1 末条与 §7——变薄只靠密度（配色 / 表格 / 判据 / 交叉引用 / 编号坐标），一字不删。低频考点压写法非删除，站台只索引非替身。

**① 跨领域公式污染**：曾混入别域对抗样本公式。对策：输出前扫一遍，非本学科公式一律删。**宁漏勿串**。

**② LaTeX 残留 & 上下标（实测两次）**：默认纯文本路线（`c = n / V`）——稳、全文可搜、闸三零风险。本条禁的是"源码残留"非"原生公式"：pandoc **未识别** `$…$` 时才把 `\frac`/`\quad` 原样印乱码——那才防。Word 原生公式（已启用实测）渲染正常（根 / 分 / 上下标 / 中文下标都正常），pandoc docx writer 默认把 `$…$`/`$$…$$` 转 OMML 原生公式对象，能力齐。启用时已改好 `verify_docx.py` 两处（实测确认）。折中：**只在最丑处用公式**（如逐差法多层分），余留纯文本——混用共存正常、闸三不受影响。

**上下标一律用 pandoc 语法：`^上标^` / `~下标~`。禁写 Unicode 上下标。**

| 写法 | 例子 | 结果 |
| --- | --- | --- |
| ✅ 语法 | `H~2~O`、`2×10^-6^`、`SO~4~^2-^`、`x^2^` | Word 原生上下标，打印不丢 |
| ❌ Unicode | `H₂O`、`2×10⁻⁶`、`SO₄²⁻`、`x²` | **宋体丢字风险** |

> ⚠️ **中文（CJK）下标连 pandoc 语法也不行，必须平排**：`k~切~`、`k~半径~` pandoc 照样不转原样印波浪号；数字与拉丁下标（`v~0~`、`x~1~`、`|AB|~min~`、`k~AB~`）正常。正解：**中文下标一律平排**——写 `k切`、`F合`、`v初`，勿写 `k~切~`。`literal_marks` 闸会直抓此类残留报 FAIL，见此别改脚本或调 pandoc，改中文下标为平排即可。

**三执行细节（实测确认）**：1. `^...^`/`~...~` 内**不能加空格**；2. 连续写、中文紧邻都正常；3. **兜底**：`prep_md.py` 自动扫残留 Unicode 转语法（已挂 `md2a5.sh`），勿依赖，主力仍直写语法；4. **范围号会被吞成下标 / 上标**（本机实测）：`~` 亦是范围号写法（`3~5V`、`2~3`、`20~30℃`），两孤立 `~` 被 pandoc 配成一对把中间整段搬进下标，且**损坏在残留检查看不见**（字面 `~` 数变 0 反判"正常"）。对策（已落地）：`prep_md.py` 自动把"夹数字间 `~`"与"其余孤立 `~`/`^`"转义 `\~`/`\^`，跑完印"孤立 ~ / ^ 已转义: N 处"；成对合法上下标不受影响。故残留检查换口径：转完字面 `~`/`^` **不必为 0**，拿残留数与 prep_md 报转义数对账，对不上那几处回 md 查。

**自检**：转完统计 `<w:vertAlign w:val="superscript"/>`，物理 / 化学一章正常 **100+ 个**；个位数 = 漏，回 md 查。

**③ 化学式残缺（最高发事故）**：残缺比写错更隐蔽，实际掉出过：

| 实际掉出 | 正确 |
| --- | --- |
| CF⁻ | Cl⁻ |
| SO₂²⁻ | SO₄²⁻ |
| CO₂²⁻ | CO₃²⁻ |
| HCO₅⁻ / HCO | HCO₃⁻ |
| AP⁺ | Al³⁺ |
| MnO / MnO²⁻ | MnO₄²⁻ |
| C₂H₂OH | C₂H₅OH |
| NH·H₂O | NH₃·H₂O |
| KClO | KClO₃ |

对策：全文搜上表左列，现任一 = 失败。拿不准式子逐拆核元素数与电荷数。

**④ 数学符号变形（静默更危险）**：上下标掉是"缺一块"一眼见；符号掉是"变另一符号"静默过。

| 原字符 | 被替成 | 后果 |
| --- | --- | --- |
| `⊄` | `α` | `l ⊄ α` → `lαα`，读不通但看不出丢字 |
| `⊂` | `c` | 同上 |
| `∥` | `\|` | 勉强认非原字符 |
| `l`（字母 L） | `1`（数字） | 三重变形 |
| `α` | `a` | 如上 |

对策：⊄ ⊂ ∥ ⊥ ∠ √ ≤ ≥ ≠ ≈ π 等须原字符，逐核。

**⑤ / ⑥ / ⑥b 表格三连坑（均已自动化，但两硬约束仍须人守）**：

| 坑 | 现象 | 谁兜住 |
| --- | --- | --- |
| ⑤ 表格渲染成空白 | 文字 XML 全在，打印大片空白 | `fix_tables.py`（固定宽 + `tblLayout=fixed` + 均分 `gridCol` + 边框 + 表头浅蓝底 + 文字居中） |
| ⑥ XML 顺序错 | 重则 Word 打不开；轻则整表不显，渲染验证照样过 | `verify_docx.py` 的 `schema_order` 闸 |
| ⑥b 字面量精确匹配 → 静默失效 | 脚本印"已修复 N 个"实际没做 | 脚本内全改容空格 / 容自闭合匹配 |

**仍须人守两条件**：1. **表格 ≤3 列**（§3 第 10 条）——脚本救不了列数；2. **勿手改 XML**，要改就改 `fix_tables.py` 重跑。⚠️ **验收要数产出物非只看"脚本没报错"**：`<w:tcPr>` 数 = 单元格数、`<w:tcW>` 同数、`<w:shd ... D9E2F3>` = 表头单元格数。数为 0 = 静默失效。

**⑦ 中文编号**：「一、（一）1.」在 Word 套不了样式。一律用 `#` `##` `###`。

**⑧ 越写越松**：长输出后半段始跳步、省略、合并。对策（三层，从结构到自查）：1. 结构兜底"先骨架后回填"（§9.2），松的只 🔵 层；2. 机械检出：每 🔵 层凑齐四问（为何 / 怎么用 / 坑 / 检验），缺一 = 松；3. 倒序核对：从最后知识点往回查非从头看。（2、3 = 闸二第 2、9 条。）允许补写尾部：发现最后板块薄了直补那板块——局部增量非整份重打。

**⑨ 转换环节丢字符**：机制见 §3 第 2 条。docx 一律走 pandoc。

**⑩ 三问答案暴露在问题旁**：答案跟问题印 = 读过即过，检索效废大半。对策：问题在板块开头、答案在板块末尾，中间隔整段讲解。

**⑪ Q3 写成套公式（实测发生）**：问"写表达式"答"令 XX=0 得 XX"——复述公式判不出真会。对策：Q3 必带具体数字或场景（§5.1）。

**⑫ 数值不自洽（最危险）**：算式按 `10^-9^` 算、电荷量却写 `10^-6^`，差 1000 倍；两处同次生成先后写、隔数百行。为何靠人眼与"回代检验"都抓不住：回代是**文内自验**，错链内部自洽，顺验每步都"对"。对策：`audit_numbers.py` 机器重算（挂 `md2a5.sh`，跑在 pandoc 前），抽 md 所有 `A = B = C` 数值等式链逐节重算，相邻两节相对误差 >1% 即报。只报**可疑**不改；字面式（`E = F/q`）自动跳；**量纲不查**（1 m 与 1 cm 它眼都 1），故辅助非保险。实测抓到第 9 章 1000 倍错（左值 20 vs 右值 0.02）。⚠️ **但误报率很高**：另次实测 22 处告警全误报。它只做行内数字机械比对不查量纲，故**告警只当"提醒再看一眼"不可据此改内容**。⚠️ **教训（比脚本细节重要）**：审计类脚本必验证"能抓到已知错误"，只验"没报错"是假验收——它自踩过：编号锚点未剔除致整条链静默跳过，现象"审计通过"实际啥没审。

**⑬ 圆场式讲法（硬禁令）**：题给 `E = 2×10^5^` 但平衡需 `E = 2×10^4^`，文档用"这组数演示场强该多大才平衡"把矛盾圆过。为何必禁：学生做题时**两 E 在脑打架**，记住非知识是混乱。硬规则：**数字实例必全局自洽。发现矛盾就改数字，禁文字圆。** 正确做法：题直给自洽平衡值 `E = 2×10^4^`，再追问"若 E 突变为 10 倍"——既自洽还带出"突变分析"。自检：写完每数字实例问"此数与前后文矛盾否？"有矛盾即改数非加解释。

**⑭ 层缺失 / 栏填"无"（验收三条同命）**：一份闸三全绿稿，通读后必改全此类：🟣 层整章为 0（20 知识点一条无，闸三没抓——`empty_field` 只查 🟠 非 🟣 条数）；🟠 栏填"无"（写"跨学科：无（纯数学方法选择）"，`vague_cross` 抓到写法但生成时照样写）；文末清单（"── 本份完成 ──"下写"包含：5 板块 19 知识点…"，`delivery_leak` 不判但已当面指 4 次）。为何危险：三条都不影响"内容对否"故机器全绿、自查易过，但它们**决定读者会不会读下去**——🟣 是保持注意力钩子，跨学科栏是建"有用"连接点，文末清单把学生稿降格报账单。对策（交付前逐项点数非凭印象）：1. `grep -c '🟣【联系·生活与跨域】'` 与 `grep -c '📍 \['` 比较——**两者必等**；2. `grep -c '跨学科：无'` 必为 **0**，同构 / 其他两栏同理；3. 文末块内不现"包含："开头清单。顺带：新增知识点时全景 / 站台 / 复习总结三处编号与计数同步改，漏改 `number_sync` 会 FAIL——但**计数词（"十九个"→"二十个"）它抓不到**，只能自改。

**⑮ 分册三专属坑（拆 90+ 页整章成上下册实测）**：一章写 90 页以上该拆上下册（按板块切，内容一字不改）。拆册踩两**仅拆册才现**闸：
- **坑 1：改标题前缀，number_sync 静默跳空**。闸按两前缀定位索引区：`## 本章知识全景` 与 `## 🗺️`。拆册写"## 本册知识全景""## 🗺️ 本册站台"两 section 即找不到，正文编号全报"全景缺"。现象迷惑：只报前 5 个（`miss_pano[:5]`）似"漏 5 编号"，实整段索引未读。→ **标题前缀一律保 `本章`**（拆的是册章还是那章）。正文写"本册""上册""下册"随便，仅标题前缀不能动。
- **坑 2：全景 / 站台现本册不存在编号 → 报"越界"**。下册讲圆锥曲线主线自会写"圆（上册 [5.1]）"，闸把 `5.1` 判越界（不在本册正文）。→ **跨册引用去方括号**写"上册 5.1"，同册内引用照用 `[N.M]`。
- **坑 3：多章合成一册按依赖链切，非按章节数均分**。若干章合并最直觉"章节数均分"（4 章切 2+2）但会把依赖链劈半。判据是**知识间依赖**：后章核心工具是否前章给的？反例：必修二 4 章（5 抛体 / 6 圆周 / 7 引力 / 8 机械能），按章节数均分 5+6 / 7+8，但 6（圆周）给"向心力"、7（引力）正充此向心力——**567 一条链**，8（能量）独立主线，正确分 **567 / 8**。→ **分册前先画依赖链**（谁概念是谁工具）按链切，非按章节数均分。

**两条流程经验**：1. **编号沿用整章编号勿册内重排**。下册从 [7.1] 起、板块从 7 起——比重编号安全（交叉引用一个不改），两册合即连续一份，合订与分册可并存。2. **题号各册内接顺**。上册板块练 1–6、章末接 7/8；下册板块练 7–11、章末接 12/13，综合题同理重排 1/2。否则读者从练 6 直跳练 12 似缺半本。

## §13 质量三闸（自检）

> **为何拆三道**：清单过长（曾至 45 条）会闭眼全勾、条条没真查。**项越多错误率越高**——人对长清单脱敏。故按**时机**拆：人工项压 10 条且条条可判，能机器查的一条不留学生手。

### 闸一 · 动笔前（前提，不勾选）

写前就该清，写完再勾无意义：
- 当前阶段（初学 / 一轮 / 二轮）→ 决定讲法重心
- 二八分配：高频写足、低频带过、偏难怪不写
- 重心基础 + 中档，压轴点缀
- 本章依赖链 / 去向链 / 调用链（站得住否）
- 确认科目册次：按读者所用教材版本走，勿按错版本顺序写

### 闸二 · 写完（人工，每条须能答"是 / 否"）

**原则：答不了"感觉还行"的条目不许存在——要么改可判要么删。**

1. 全景对清单过：有无该讲没讲、有无两条实一条
2. 每 🔵 四问齐否（为何 / 怎么用 / 坑 / 检验）—— 逐条打勾
3. Q3 带具体数字或具体句子否（语文版是**给句子**非问用法名）
4. 问题在板块开头、答案在板块末尾否（贴一起 = 检索作废）
5. 例题有解析；习题与综合题**没**给答案 / 解析 / 思路
6. 存疑点编号 [S1]；**上章挂 S 逐处置了**（清算 / 挂靠 / 标不要求）
7. 站台未现正文无结论；正文未写"详见站台"
8. 无"见前文 / 显然 / 同理可得"；未写方法名
9. 🔴 **倒序核对**：最后板块按 🔵 四问逐条打勾
10. 🔴 **过一遍 §11 ⓪–⑬**（失败模式逐条问"此章犯了吗"）

> **第 9、10 条单独点名，勿当普通条目。** 第 9 条：尾部衰减客观，从前往后查会越看越满意查不出——必倒查（实测炸三次全在末）。第 10 条：§11 每条皆真出过事才写，靠它自查比临时想"我哪可能错"可靠——人想不出没见过的错。

### 闸三 · 交付前（机器，一条不手勾）

```bash
python3 scripts/verify_docx.py 输出.docx 源.md
```

14 项一次跑完，**分三组**（括号里脚本函数名，改脚本按名找）：

**docx 侧（9 项，看转出 docx）**

| 项 | 查什么 | 判 FAIL / WARN 条件 |
| --- | --- | --- |
| `xml_wellformed` | XML 能否解析 | 解析失败 |
| `schema_order` | pPr / tblPr / tcPr 子元素顺序 | 任一类顺序违规 |
| `tables` | `tcPr` 数 = 单元格数、`tcW`、表头底色 | **`tcPr` = 0 → 静默失效** |
| `shading` | 🟢 / 🟠 / ⚠ 三类底纹 + 🔮 左边框 | 三类全 0、或只 🟢 一类 → WARN |
| `vertalign` | 上下标计数 | 0 或个位数 → WARN（文科为 0 属常） |
| `chars` | md ↔ docx 字符对账 | 任一字符丢失 |
| `endblock_dup` | 文末结束标记出现次数 | ≥2 次 = 文末块被复制 |
| `delivery_leak` | 写给 AI 验收话混进文档 | 命中"请验收"之类 → FAIL |
| `literal_marks` | `~x~` / `^x^` 未转 vertAlign | 有残留 → FAIL（中文下标栽此） |

**md 侧（4 项，看源 md，须传第二参才跑）**

| 项 | 查什么 | 判 FAIL / WARN 条件 |
| --- | --- | --- |
| `empty_field` | 🟠 同构 / 跨学科填"无"或留 `__` | FAIL |
| `vague_cross` | 跨学科栏只写光秃秃学科名（"数学"两字） | FAIL |
| `struct_complete` | 必备件清点（三问 / 例题 / 习题 / 易错 / 存疑点 / 站台 / 复习总结） | WARN（不阻断，防误伤非讲义文档） |
| `number_sync` | 正文 📍[N.M] / 全景 / 站台 编号三方一致 | FAIL |

**外部（1 项）**

| 项 | 查什么 | 判 FAIL 条件 |
| --- | --- | --- |
| `render` | LibreOffice 渲染 + 页数 | 没产出 PDF |

⚠️ **不传 md 源只跑 docx 侧 9 项**——md 侧四闸跳过（脚本报 SKIP）。故命令必带第二参：`python3 scripts/verify_docx.py 输出.docx 源.md`。

**页数是报告项非闸门**——超预期时人判"真需要"还是"注水"，不自动判错。

**改完脚本必重跑自测**：

```bash
python3 scripts/verify_docx.py --selftest
```

它把七已知错误逐个注入确认抓得到。**判据是"错误被报出"非"脚本没崩"**——脚本自静默失效是最阴失败模式（见 ⑥b 与 ⑬）。

### 收尾

- 进度索引已更新（含页数）
- 末尾写"── 本份完成 ──"块（面向学生一句收尾；不含交付清单，不写"请验收"）

## §14 执行流程

### 14.1 开工前（生成新章必做，勿跳）

0a. **读进度索引存疑点总账** → 上章 S 逐条处置（清算 / 挂靠第 X 章 / 标不要求）（见 §5.4。第 9→10 章漏 S2 即跳此步。）
0b. **确认科目册次**：按读者所用教材版本走；册次拿不准问读者课本目录勿猜——版本章节顺序异，猜错整份错位。
0c. 确认当前阶段（初学 / 一轮 / 二轮）→ 决定讲法重心。

### 14.2 生成

指定科目 + 章 → 精讲版（md + A5 docx）。篇幅由内容定，勿指定档位。

### 14.3 转换（八步，顺序不能换——全固化于 md2a5.sh）

```
md 写好
  ↓ ① prep_md.py    中文引号成对 + Unicode 上下标→^x^/~x~
  ↓ ② audit_numbers.py  数值审计（有可疑会停问）
     ⚠️ **误报率极高**（只做行内数字机械比对不查量纲；实测 22 处全误报）。
     告警只当"提醒再看一眼"**不可据此改内容**；算术把关靠出题时自代回验。
  ↓ ③ make_ref.py   缺 A5 模板即现场重建
  ↓ ④ pandoc        搬运（临时目录由 env.sh 指定）
  ↓ ⑤ fix_tables.py 修表格
  ↓ ⑥ colorize.py   语义上色
  ↓ ⑦ add_pagenum.py 注入页脚页码（居中 X / Y）
  ↓ ⑧ normalize_order.py schema 顺序归一化（兜底顺序漂移）
  ↓ cp 回目标位置 + 验证文件非空   ← 不做验证=换环境静默失败
docx
```

**①② 本轮新增两保险**，皆"不做即出事"：①不做 → 宋体打印丢上下标（第 10 章漏 275 处）；②不做 → 数值错静默过（第 9 章 1000 倍错）。中间产物在临时目录做、cp 回后必验证——写死。⚠️ 本机 `/tmp` 落 C 盘，跑前用 `env.sh` 把 `TMPDIR/TEMP/TMP` 指 S 盘。

### 14.4 读者用（管"读者回来时怎么接"非"怎么生成"）

- **对答案**：答错 → 指卡哪步让读者自重走；答对 → 确认关键步。**勿直报答案**除非读者要。
- **存疑点**：读者报 `[S1]` 即直答那个，勿读者复述背景（编号为此存）。
- **回看**：⏰ 日期登进度索引，届时回重做三问。
